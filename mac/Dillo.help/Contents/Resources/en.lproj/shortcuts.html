Keyboard shortcuts

Menu commands use the Command key. Dillo's own bindings, set in ~/.dillo/keysrc, use Control.

ShortcutAction
Command-TNew tab
Command-NNew window
Command-OOpen file
Command-LOpen location
Command-WClose tab
Control-FFind text on the page
Control-RReload the page

Apple Shortcuts

Dillo accepts automation URLs in the form dillo:https://example.com. In Shortcuts, join dillo: to a URL and pass it to the system Open URLs action.
